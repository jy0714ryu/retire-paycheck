## 2차 지시 (같은 날)
- **1,500만 절벽 판정 통일**: `buildMonths` 세율을 `월 인출 × 12` 고정 → 그 해 실제 인출 개월 수(개시월 반영, `buildGauges` 와 같은 기준). 달력 경고도 게이지 값을 그대로 씀. 예: 10월 개시·월 200만 → 2026년 600만(저율 5.5%), 2027년부터 16.5%.
- **현금성 잔액 0 인출 차단**: `Account.withdrawalActive = isWithdrawing && balance > 0` 을 엔진·계획·세금·달력 공통 게이트로. 잔액 0 이면 '인출 개시' 스위치 비활성 + "현금성 잔액을 먼저 입력하세요". 이미 켠 계좌의 잔액을 0으로 지우면 경고(끄기는 가능), 월 인출 > 잔액이면 부족 경고. ⚠️ 기존 사용자 중 잔액 없이 인출만 켜 둔 경우 업데이트 후 달력 연금이 0 으로 바뀜(의도).

## 결정 기록
- **기본 보기 = 총계** (앱 정체성 "은퇴 월급"). 기존 사용자 선택은 구 키 `calendar_view`(bool)에서 이어받음: 배당 전체→배당금, 통장 입금→총계. 새 키 `calendar_view_mode`.
- 총계 = 세후 실수령(일반계좌 배당 + 연금·ISA 인출 + 이자). ISA·연금 계좌 배당은 빠지고 하단 안내로만.
- 연금 보기의 계좌별 금액은 **세전 월 인출액**(계좌별 세금 배분은 엔진이 하지 않음 — 카드 큰 숫자가 세후 합).
- 계좌 필터 칩은 배당금 보기에서만.
- 스토어 이름의 "세금 경보"는 이번에 바꾸지 않음(검색어 영향 — 별도 결정).
